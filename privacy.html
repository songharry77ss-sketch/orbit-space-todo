ORBIT 개인정보처리방침

ORBIT 우주 할 일 · 시행일 2026년 10월 20일

한 줄 요약

ORBIT은 서버가 없는 앱입니다. 할 일은 사용하는 기기의 브라우저에만 저장되고, 운영자가 따로 모으거나 보관하는 개인정보는 없습니다.

저장하는 정보

  • 할 일과 행성(카테고리): 제목, 메모, 날짜, 우선순위 등은 브라우저 저장소(localStorage)에만 저장됩니다. 다른 곳으로 전송되지 않습니다.
  • Google 연결 정보: Google 캘린더를 연결하면 접근 토큰이 브라우저 탭에만 잠시(최대 1시간) 보관되고, 연결된 캘린더 아이디와 동기화 기록이 브라우저 저장소에 남습니다.
  • 쿠키나 광고 · 분석 추적 도구를 쓰지 않습니다.

Google 캘린더 데이터 사용

사용자가 직접 「Google 계정으로 연결」을 누른 경우에만 아래 권한을 요청하며(세 번째 권한은 사용자가 「내 구글 일정도 함께 보기」를 켤 때만 따로 요청), 브라우저에서 Google 캘린더 API와 직접 통신합니다. 데이터는 ORBIT 운영자를 포함한 제3자에게 전달되지 않습니다.

  • calendar.app.created: 사용자 계정에 「ORBIT 할 일」 캘린더를 만들고, 그 캘린더 안의 일정만 만들고 고치고 지웁니다. 사용자의 다른 캘린더는 바꾸지 않습니다.
  • calendar.calendarlist.readonly: 어떤 캘린더가 있는지 확인해 「ORBIT 할 일」 캘린더를 찾고 일정 색을 맞춥니다.
  • calendar.events.readonly(선택): 사용자가 켠 경우에만, 다른 캘린더 일정을 읽어 ORBIT 화면에 함께 보여 줍니다. 읽기만 합니다.

Google에서 받은 정보는 위 기능에만 쓰며, 광고나 다른 목적으로 쓰거나 판매하지 않습니다. ORBIT의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

연결 끊기와 삭제

  • ORBIT 캘린더 화면 → 「캘린더 연동」 → 「연결 끊기」로 언제든 연결을 끊을 수 있습니다.
  • Google 계정의 서드파티 앱 접근 관리에서도 권한을 없앨 수 있습니다.
  • 브라우저에 저장된 데이터는 설정 → 데이터 → 「모두 지우기」 또는 브라우저 사이트 데이터 삭제로 지워집니다. 「ORBIT 할 일」 캘린더는 Google 캘린더에서 직접 지울 수 있습니다.
