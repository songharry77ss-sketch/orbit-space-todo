# ORBIT 우주 할 일

할 일 목록이 주인공인 투두리스트입니다. 행성은 카테고리, 할 일은 그 행성을 도는 위성입니다. 불꽃 버튼을 누르면 할 일이 태양으로 날아가 집중 타이머가 시작되고, 실사 태양이 타오르는 집중 화면에서 단계를 체크하며 끝냅니다. 3D 행성계는 「우주」 탭에 있습니다.

- 배포 주소: https://orbit-space-todo.vercel.app (Vercel) · https://songharry77ss-sketch.github.io/orbit-space-todo/ (GitHub Pages)
- 외부 라이브러리 없이 HTML · CSS · JavaScript 와 직접 만든 WebGL 3D 엔진으로 동작하고, 데이터는 브라우저(localStorage)에 저장됩니다.

## 화면 (2026-10 개편)

휴대폰은 아래 탭 4개와 떠 있는 + 버튼, 넓은 화면(900px 이상)은 왼쪽 메뉴 · 가운데 목록 · 오른쪽 상세 패널(1200px 이상)로 바뀝니다.

| 탭 | 내용 |
| --- | --- |
| 오늘 | 지금 집중 중 카드 · 지난 일 · 오늘 · 완료(접힘). 오늘의 구글 일정도 함께. 넘치면 줄 높이를 줄여 한 화면에 모두 보입니다 |
| 예정 | 주간 줄에서 날짜를 고르고 아래 날짜별 목록으로 봅니다. 「달력」으로 바꾸면 월간 · 주간 달력과 고른 날의 목록 |
| 행성 | 행성(카테고리)별 남은 일 · 진행. 손잡이를 끌어 순서 바꾸기, 행성을 누르면 그 행성의 할 일, 「모든 할 일」에서 남은 일 · 높음 · 지난 일 · 기한 없음 · 완료로 거르고 행성 · 우선순위 · 기한별로 묶어 봅니다 |
| 우주 | 하나의 궤도를 함께 도는 실사 행성계(3D). 위성을 태양으로 끌면 집중, 다른 행성에 놓으면 이동, 행성을 궤도를 따라 끌면 순서 변경. 이 탭이 보일 때만 3D를 그려 배터리를 아낍니다 |

- **글자와 색**: 글자는 늘 불투명한 면 위에 놓이고, 다크 · 라이트 테마 모두 보이는 글자 전부가 WCAG 대비 기준(본문 4.5:1) 이상입니다(가장 흐린 글자 약 5.2:1). 테마는 기기 설정을 따르며 설정에서 고정할 수 있고, 「글자 크게」로 목록 · 상세 글자를 키웁니다.
- **우선순위 3단계**: 높음(빨강) · 보통(주황) · 낮음(파랑) · 미정. 할 일 왼쪽 동그라미 테두리 색으로 보여 줍니다.
- **집중**: 여러 개를 동시에 태울 수 있고, 앱을 닫았거나 컴퓨터가 잠든 시간은 집중 시간에서 뺍니다. 오늘 할 일을 모두 끝내면 축하 연출이 나옵니다.

## 사용법

처음 실행하면 빈 목록으로 시작하고, 안내에서 「예시로 둘러보기」를 고를 때만 예시 할 일을 불러옵니다.

| 동작 | 방법 |
| --- | --- |
| 할 일 추가 | 휴대폰은 + 버튼, 넓은 화면은 목록 위 입력창(`N`). `#행성이름` `!1`~`!3` 「내일」「다음주 금요일」「오후 3시」「12/25」를 알아듣고 칩에 미리 보여 줍니다. 오늘 탭은 오늘, 예정 탭은 고른 날짜, 행성 화면은 그 행성이 기본값 |
| 완료 | 왼쪽 동그라미, 휴대폰은 줄을 오른쪽으로 밀기. 알림에서 되돌리기 |
| 내일로 미루기 | 휴대폰에서 줄을 왼쪽으로 밀기 |
| 집중 시작 · 멈춤 | 줄 오른쪽 불꽃 버튼, 상세의 「집중 시작」. 집중 카드를 누르면 전체 화면 집중 |
| 상세 편집 | 할 일을 누르면 상세. 날짜 · 우선순위 · 오늘 할 일 · 반복은 칩으로, 단계 · 메모, 행성 옮기기 |
| 행성 순서 | 행성 탭이나 설정에서 손잡이 끌기(키보드는 위아래 화살표), 우주 탭에서 행성을 궤도를 따라 끌기. 실행 취소 가능 |
| 우선순위 정리 | 미정인 오늘 할 일이 3개 이상이면 「정리하기」. `1` `2` `3` 으로 고르고 `→` 로 건너뜀 |

단축키: `N` 할 일 추가 · `/` 또는 `Ctrl+K` 검색 · `1` `2` `3` `4` 오늘 · 예정 · 행성 · 우주 · `Esc` 닫기 · 우주 탭에서 `+` `−` 확대 · 방향키 시점 · `0` 전체 보기 · `R` 자동 회전 · `?` 조작 안내

| 우주 탭 조작 | 마우스 · 키보드 | 터치 |
| --- | --- | --- |
| 시점 돌리기 | 빈 공간 드래그, 방향키 | 한 손가락 드래그 |
| 확대 · 축소 | 휠, `+` `−` | 두 손가락 오므리기 · 벌리기 |
| 행성 가까이 보기 | 행성이나 이름표 클릭(아래 카드에 할 일) | 행성 탭 |
| 위성 끌기 | 누른 채 끌기(패드는 탁 탁 두드려 끌기도). 태양에 놓으면 집중 | 손가락으로 바로 끌기 |

Google Tasks 와 Microsoft To Do 에서 좋은 기능을 가져왔습니다: 나의 하루(오늘 할 일), 제안, 단계, 반복, 메모, 빠른 추가, 날짜와 시간, 캘린더 보기.

## 캘린더 주간 보기와 연동

- **주간 보기**: 일주일을 7개 열로 펼쳐 날짜마다 할 일을 카드로 보여 줍니다. 시간이 있는 일이 먼저 시간순으로 나오고, 카드에서 바로 완료 체크, 다른 날짜로 끌어 옮기기(실행 취소 가능), 날짜 아래 「추가」로 그날 할 일 넣기가 됩니다. 휴대폰에서는 날짜별 세로 목록이 되고 오늘부터 보입니다.
- **휴대폰 월간 보기**: 날짜를 선택하면 달력 아래에 그날의 할 일 목록과 「할 일 추가」 버튼이 표시됩니다. 목록에서 상세를 열거나 바로 완료하고, 추가 버튼으로 선택한 날짜의 입력창에 이동할 수 있습니다.
- **캘린더 키보드 조작**: 월간 달력에 포커스를 두고 `←` `→` 는 하루, `↑` `↓` 는 일주일씩 이동합니다. `Home` · `End` 는 주의 처음 · 끝, `Ctrl`/`Cmd`와 함께 누르면 달의 처음 · 끝으로 갑니다. `PageUp` · `PageDown` 은 이전 · 다음 달, `Shift`와 함께 누르면 이전 · 다음 해로 이동합니다. `Enter` 또는 `Space`로 선택하며, 데스크톱에서는 날짜 상세도 열립니다.
- **내 캘린더로 보내기**: 캘린더 아래 「캘린더 연동」(또는 설정 → 데이터)에서 마감일이 있는 할 일을 .ics 파일로 받아 구글 · 애플 · 아웃룩 · 삼성 캘린더에 넣습니다. 시간이 없으면 하루 종일 일정, 있으면 30분 일정(10분 전 알림 선택)이 되고, 반복 설정도 함께 넘어갑니다.
- **할 일 하나만 보내기**: 상세 화면 마감 아래 「캘린더에 추가」에서 Google · Outlook(새 창으로 일정 만들기) 또는 .ics 파일을 고릅니다.
- **다른 캘린더 가져오기**: 다른 캘린더에서 내보낸 .ics 파일을 고르면 미리 보기 후 원하는 행성에 할 일로 넣습니다. 지난 일정은 뺄 수 있고, 반복 일정은 오늘 이후 가장 가까운 날짜와 반복 설정으로 바뀌며, 같은 파일을 다시 가져와도 중복되지 않습니다.
- **Google 캘린더 바로 연결**: 「캘린더 연동」 → 「Google 계정으로 연결」. 구글 캘린더에 「ORBIT 할 일」 캘린더가 생기고 마감일이 있는 할 일이 우선순위 색(높음 빨강 · 보통 노랑 · 낮음 파랑, 완료 회색)과 10분 전 알림으로 들어갑니다.
  - ORBIT에서 추가 · 수정 · 완료 · 삭제하면 2초 안에 구글에도 반영됩니다. 구글 캘린더에서 날짜나 제목을 바꾸면 ORBIT에도 반영되고, 그 일정을 지우면 할 일은 「기한 없음」으로 옮겨집니다.
  - 「ORBIT 할 일」 캘린더에 구글에서 직접 만든 일정은 ORBIT 할 일이 됩니다. 그래서 다른 기기의 ORBIT도 같은 구글 계정으로 연결하면 마감일 있는 할 일이 서로 이어집니다.
  - (선택) 「캘린더 연동」에서 「내 구글 일정도 ORBIT에 함께 보기」를 켜면 일정 있는 시간대만 읽는 권한(`calendar.events.freebusy`, 민감하지 않음 · 경고 없음)을 묻고, 내 다른 구글 캘린더의 바쁜 시간이 ORBIT 월간 · 주간 캘린더와 「오늘 할 일」 보드에 빗금 칩(「일정 있음 ~끝나는 시각」)으로 보입니다. 「일정 제목도 보고 싶어요」를 고르면 경고 화면 안내를 먼저 보여 준 뒤 제목 읽기 권한(`calendar.events.readonly`)을 요청해 제목까지 보여 줍니다. 칩을 누르면 구글 캘린더에서 열립니다.
  - 원래 있던 구글 일정은 바꾸거나 지우지 않습니다(권한도 요청하지 않음). 서버 없이 브라우저가 구글과 직접 통신하고, Google 정책상 연결은 1시간마다 새로 받아야 해서 끊기면 캘린더 위 「다시 연결」을 한 번 누르면 됩니다. 그동안의 변경은 다시 연결할 때 올라갑니다.
- 애플 · 아웃룩 · 삼성 캘린더는 .ics 파일로 주고받습니다.

### 구글 캘린더 연결 설정 (완료됨 · 다시 만들 때 참고)

현재 Google Cloud 프로젝트 `orbit-512205`(ORBIT)에 웹 클라이언트가 있고, 앱은 **프로덕션**으로 게시되어 있습니다. 기본 연결 권한 두 개(`calendar.app.created`, `calendar.calendarlist.readonly`)는 Google 분류상 민감하지 않은 범위라 심사 없이 누구나 경고 없이 연결합니다. 「내 구글 일정 함께 보기」의 기본(일정 있는 시간대 · `calendar.events.freebusy`)도 민감하지 않은 범위라 경고가 없습니다. 제목까지 보는 선택(`calendar.events.readonly`)만 민감한 범위라, 심사를 통과하기 전에는 「확인되지 않은 앱」 안내가 나옵니다(앱 안에서 고급 → 이동 방법을 먼저 안내함 · 심사 자료: docs/google-oauth-verification.md).

Google 로그인을 쓰려면 Google Cloud에서 무료 OAuth 클라이언트 ID를 하나 만들어야 합니다. 비밀 키가 아니라 공개해도 되는 값입니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고(예: ORBIT), **API 및 서비스 → 라이브러리**에서 **Google Calendar API**를 사용 설정합니다.
2. **Google 인증 플랫폼(OAuth 동의 화면)**에서 앱 이름 「ORBIT」, 지원 이메일을 넣고 대상은 **외부**로 고릅니다. 앱 홈페이지는 `https://orbit-space-todo.vercel.app`, 개인정보처리방침은 `https://orbit-space-todo.vercel.app/privacy.html`.
3. **데이터 액세스(범위)**에 `.../auth/calendar.app.created`, `.../auth/calendar.calendarlist.readonly`, `.../auth/calendar.events.freebusy`(민감하지 않음), `.../auth/calendar.events.readonly`(민감 · 선택) 를 추가합니다.
4. **클라이언트 → 클라이언트 만들기 → 웹 애플리케이션**. **승인된 JavaScript 원본**에 `https://orbit-space-todo.vercel.app`, `https://songharry77ss-sketch.github.io`, `http://localhost:5173` 을 넣습니다(리디렉션 URI는 비워 둠).
5. 만들어진 클라이언트 ID(`…apps.googleusercontent.com`)를 `js/gcal.js` 맨 위 `GCAL_CLIENT_ID` 에 넣고 배포하면 모든 사용자에게 「Google 계정으로 연결」이 보입니다. 배포 전에 시험만 하려면 앱의 「캘린더 연동」 창에 붙여 넣어도 됩니다(그 브라우저에만 저장).
6. 공개 범위: 앱이 **테스트** 상태면 **대상 → 테스트 사용자**에 넣은 계정(최대 100명)만 연결할 수 있고, 연결할 때 「확인되지 않은 앱」 안내가 나오면 **고급 → ORBIT(으)로 이동**을 누르면 됩니다. 누구나 경고 없이 쓰게 하려면 **앱 게시 → 인증 신청**을 하면 됩니다(캘린더 범위는 민감한 범위라 Google 검토가 필요합니다).

휴대폰에서는 상단 바가 두 줄로 바뀌고, 오늘 할 일 보드는 입력창 위에서 접고 펼칩니다. 상세 화면은 아래에서 올라오는 시트(손잡이를 끌어내려 닫기)가 되며, 「지금 집중 중」 바는 입력창 바로 위에 붙습니다. 목록 보기는 세로로 읽는 방식이 기본이고, 「보드」로 바꾸면 열을 옆으로 넘겨 봅니다. 화면이 느려지면 렌더링 해상도를 자동으로 낮춰 부드럽게 유지합니다.

스토어 앱은 모두 같은 웹앱(배포 주소)을 감싼 껍데기라, 웹을 배포하면 앱 내용도 함께 바뀝니다.

| 스토어 | 방식 | 위치 |
| --- | --- | --- |
| Google Play (Android) | TWA · Bubblewrap, 패키지 com.craving.orbit | android/tools/twa.js, .well-known/assetlinks.json |
| App Store (iPhone · Apple Silicon Mac) | Expo WebView + 네이티브 Google 로그인, EAS 클라우드 빌드 | ios-app/ (원본 C:/Users/opqrt/orbit-ios) |
| Microsoft Store (Windows) | PWABuilder 로 만든 MSIX, 패키지 CRAVING.ORBIT · Store ID 9MVXK376MQSS | manifest.webmanifest, store/windows-art (로고) |

Mac 은 App Store 의 iPhone 앱을 Apple Silicon Mac 에서도 받을 수 있게 켜 두었고(가격 및 사용 가능 여부), Intel Mac 은 Chrome · Edge · Safari 설치로 씁니다.
스토어 이미지는 `node store/shoot.js` 로 다시 찍습니다. 한 폴더만 찍으려면 `ORBIT_ONLY` 에 play, appstore, appstore-63, desktop 중 하나를 넣습니다.

| 바로 열기 | `index.html` 더블클릭. 텍스처는 `js/textures-inline.js` 에서 읽어 오프라인으로도 동작합니다 |
| 로컬 서버 | `python -m http.server 8080` 후 http://localhost:8080 |
| 배포 | `main` 에 푸시하면 GitHub Pages 가 자동 배포합니다. Vercel(스토어 앱이 여는 주소)은 레포 폴더에서 `vercel --prod --yes` 로 배포합니다 |

### 회귀 검사

데이터 · 날짜 파서 검사는 Node.js만 있으면 실행됩니다.

```sh
node tests/data-regression.cjs
node tests/motion-regression.cjs
```

브라우저 검사는 `android/tools/node_modules/puppeteer-core`와 설치된 Chrome을 사용합니다. 프로젝트 루트에서 `python -m http.server 8080`으로 서버를 켜 두고, 다른 터미널에서 실행합니다.

```sh
node tests/ui-regression.cjs
node tests/mobile-stability.cjs
```

기본 대상은 `http://127.0.0.1:8080/`이며 다른 주소를 인자로 줄 수 있습니다. Chrome 경로가 다르면 `CHROME_PATH` 환경 변수로 지정합니다.

화면 검사(`ui-regression`)는 오늘 · 예정 · 달력 · 행성 · 상세 · 추가 시트 · 설정 · 집중 화면을 다크와 라이트로 열어 **보이는 글자 전부의 대비**(본문 4.5:1 · 큰 글자 3:1)를 재고, 휴대폰에서 오늘 할 일이 스크롤 없이 보이는지 · 320~820px에서 가로로 넘치지 않는지 · 추가 · 완료 · 밀어서 완료/내일로 · 집중 · 상세 편집 · 검색 · 설정이 동작하는지 확인합니다. 캡처는 임시 폴더의 `orbit-ui`에 저장됩니다.

모바일 안정성 검사는 휴대폰 세로 · 가로에서 모든 입력칸이 16px 이상(iOS 입력 확대 방지)인지, 키보드가 열리면 추가 시트가 그 위로 올라가는지, 일부러 확대한 화면을 되돌리지 않는지 확인합니다. 실제 iPhone 키보드 동작은 기기에서 따로 확인합니다.
