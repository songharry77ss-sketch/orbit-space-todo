# ORBIT 우주 할 일

실제 행성 사진으로 만든 우주에서 할 일을 관리하는 투두리스트입니다. 행성은 카테고리, 그 주위를 도는 위성은 할 일입니다. 위성을 가운데 태양으로 끌어다 놓으면 태양이 타오르며 집중 타이머가 시작됩니다.

- 배포 주소: https://songharry77ss-sketch.github.io/orbit-space-todo/
- 외부 라이브러리 없이 HTML · CSS · JavaScript(WebGL) 로 만들었고, 데이터는 브라우저(localStorage)에 저장됩니다.

## 화면

- **우주**: 은하수 파노라마 위로 별이 반짝이고 우주 먼지가 천천히 떠다닙니다. 행성계는 저마다의 리듬으로 둥실 떠 있고, 마우스를 움직이면 깊이에 따라 시차가 생깁니다.
- **행성**: 지구 · 목성 · 화성 · 해왕성 · 토성 · 금성 · 천왕성 · 수성 · 달. 실제 지도 텍스처를 입힌 구체가 자전하고, 태양 쪽에서 빛을 받습니다. 지구는 구름층과 밤의 도시 불빛까지, 토성은 고리까지 표현됩니다.
- **위성(할 일)**: 기울어진 궤도를 돌며 행성 뒤로 숨었다 나타납니다. 중요한 일은 금빛 고리, 기한이 지난 일은 붉게 맥박칩니다. 행성에 마우스를 올리면 공전이 멈추고 궤도가 펼쳐집니다.
- **태양(집중)**: 위성을 태양에 놓으면 점화됩니다. 여러 개를 동시에 태울 수 있고, 태울수록 코로나와 불꽃이 커집니다. 태양 아래 카드에서 타이머를 보고 ✓ 로 완료하면 초신성처럼 터집니다.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 할 일 추가 | 아래 입력창에 쓰고 Enter. `#행성이름` `!`(중요) 「내일」「다음주 금요일」「오후 3시」「12/25」를 알아듣고, 입력하는 동안 행성과 날짜 칩에 미리 보여 줍니다 |
| 집중 시작 | 위성을 태양으로 끌어다 놓기, 또는 상세 화면의 「태양에 올려 집중 시작」 |
| 완료 | 태양 아래 카드의 ✓, 목록의 동그라미. 실행 취소 가능 |
| 궤도로 되돌리기 | 집중 카드나 타오르는 위성을 행성으로 끌어다 놓기. 타이머는 일시정지 |
| 카테고리 이동 | 위성을 다른 행성으로 끌어다 놓기 |
| 보기 | 오늘(기본) · 전체 · 캘린더. 캘린더에서는 할 일을 다른 날짜로 끌어 옮깁니다 |
| 오늘의 미션 | 태양이나 오른쪽 위 진행 링을 누르면 남은 일, 지난 일, 제안이 모입니다 |
| 행성 관리 | 설정에서 이름과 천체를 고르고, 삭제할 때 할 일을 다른 행성으로 옮길 수 있습니다 |

단축키: `N` 새 할 일 · `/` 또는 `Ctrl+K` 검색 · `1` `2` `3` 보기 전환 · `T` 오늘의 미션 · `Esc` 닫기

Google Tasks 와 Microsoft To Do 에서 좋은 기능을 가져왔습니다: 나의 하루(오늘 할 일), 제안, 중요 표시, 단계, 반복, 메모, 빠른 추가, 날짜와 시간, 캘린더 보기.

## 기기별 사용

| 기기 | 방법 |
| --- | --- |
| Windows · Mac (Chrome · Edge) | 배포 주소를 열고 주소창 오른쪽 **설치** 아이콘 → 데스크톱 앱처럼 실행 |
| Mac (Safari 17+) | 파일 메뉴 → **Dock에 추가** |
| 갤럭시 · Android | Chrome 또는 삼성 인터넷 메뉴 → **홈 화면에 추가** / **앱 설치** |
| iPhone · iPad | Safari 공유 버튼 → **홈 화면에 추가** |

휴대폰에서는 상단 바가 두 줄로 바뀌고, 상세 화면은 아래에서 올라오는 시트(손잡이를 끌어내려 닫기)가 되며, 집중 카드는 입력창 위 가로 스크롤 독으로 모입니다. 화면이 느려지면 렌더링 해상도를 자동으로 낮춰 부드럽게 유지합니다.

App Store · Play Store 에 올리려면 이 폴더를 네이티브 껍데기로 감싸면 됩니다.

```bash
npm init -y && npm i @capacitor/core @capacitor/cli
npx cap init "ORBIT" "com.example.orbit" --web-dir .
npx cap add ios      # Mac + Xcode 필요
npx cap add android  # Android Studio 필요
```

Android 는 [PWABuilder](https://www.pwabuilder.com) 에 배포 주소를 넣어 Play Store 용 패키지를 만들 수도 있습니다.

## 실행

| 방법 | 설명 |
| --- | --- |
| 바로 열기 | `index.html` 더블클릭. 텍스처는 `js/textures-inline.js` 에서 읽어 오프라인으로도 동작합니다 |

## 구조

```
index.html             마크업
css/style.css          디자인 토큰 · 글래스 UI · 시트 · 캘린더 · 반응형
js/bodies.js           천체 카탈로그(텍스처 · 색 · 크기 · 자전 · 기울기)
js/gl.js               WebGL 렌더러: 은하수 · 태양 · 행성 · 토성 고리 · 궤도선 셰이더
js/fx.js               2D 이펙트: 우주 먼지 · 불씨 · 폭발 · 드래그 궤적
js/scene.js            레이아웃 · 떠다니는 움직임 · 위성 공전 · 선택 · 드래그 앤 드롭
js/panel.js            상세 시트: 할 일 · 행성 · 날짜 · 오늘의 미션
js/calendar.js         월 캘린더
js/app.js              초기화 · 보기 전환 · 커맨드 바 · 검색 팔레트 · 모달 · PWA
js/store.js / utils.js 데이터 · 날짜와 자연어 파서
js/textures-inline.js  file:// 로 열 때 쓰는 텍스처 묶음 (자동 생성)
textures/              행성 · 태양 · 은하수 텍스처와 미리 렌더한 썸네일
sw.js                  오프라인 캐시
```
