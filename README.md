# ORBIT 우주 할 일

실제 행성 사진으로 만든 우주에서 할 일을 관리하는 투두리스트입니다. 행성은 카테고리, 그 주위를 도는 위성은 할 일입니다. 위성을 가운데 태양으로 끌어다 놓으면 태양이 타오르며 집중 타이머가 시작됩니다.

- 배포 주소: https://orbit-space-todo.vercel.app (Vercel, `main` 푸시 시 자동 배포) · https://songharry77ss-sketch.github.io/orbit-space-todo/ (GitHub Pages)
- 외부 라이브러리 없이 HTML · CSS · JavaScript 와 직접 만든 WebGL 3D 엔진으로 동작하고, 데이터는 브라우저(localStorage)에 저장됩니다.

## 화면

- **3D 우주**: 원근 카메라로 본 태양계입니다. 행성은 태양을 중심으로 한 동심 궤도에 놓이고 계 전체가 아주 천천히 돌며, 조작하는 동안에는 멈춥니다. 화면 크기와 열린 패널에 맞춰 카메라가 자동으로 구도를 다시 잡습니다.
- **배경**: 은하수 파노라마 위로 별이 반짝이고 우주 먼지가 떠다니며, 마우스를 움직이면 카메라가 살짝 따라 움직입니다.
- **행성**: 지구 · 목성 · 화성 · 해왕성 · 토성 · 금성 · 천왕성 · 수성 · 달. 실제 지도 텍스처를 입힌 3D 구체가 자전하고 태양 쪽에서 빛을 받습니다. 지구는 구름층·바다 반사광·밤의 도시 불빛, 토성은 행성과 서로 그림자를 드리우는 고리까지 표현됩니다.
- **위성(할 일)**: 기울어진 3D 궤도를 돌며 행성 뒤로 숨었다 나타납니다. 중요한 일은 금빛 고리, 기한이 지난 일은 붉은 고리로 표시됩니다. 행성에 마우스를 올리면 궤도면이 화면을 향해 펼쳐지고 위성 옆에 할 일 이름이 나타납니다(설정에서 항상 표시 가능).
- **태양(집중)**: 위성을 태양에 놓으면 점화되어 불타는 위성이 태양 주위를 돕니다. 여러 개를 동시에 태울 수 있고, 태울수록 코로나와 홍염이 커집니다. 입력창 바로 위 「지금 집중 중」 바에 큰 타이머 · 다음 단계 · 멈춤 · 완료가 모입니다.

## 한눈에 보기와 우선순위

- **행성 이름표**: 행성마다 이름 아래에 남은 할 일 제목이 우선순위 색 막대와 함께 최대 3개(휴대폰 2개)까지 붙고, 지난 일과 오늘 시각도 함께 보입니다. 이름표끼리 겹치거나 태양 · 행성 · 보드를 가리면 방향을 바꿔 보고, 그래도 자리가 없으면 개수만 보여 줍니다. 할 일 줄에 마우스를 올리면 그 위성이 강조되고, 누르면 상세가 열리며, 끌면 위성처럼 옮길 수 있습니다.
- **휴대폰의 오늘 할 일**: 화면 왼쪽 위 「오늘 할 일」 버튼을 누르면 데스크톱 보드와 같은 우선순위별 목록이 아래에서 올라옵니다. 바깥을 누르면 닫힙니다.
- **목록 보기 (상단 「목록」, 단축키 `3`)**: 날짜와 상관없이 모든 할 일을 열로 펼쳐 한 화면에 보여 줍니다. 묶는 기준을 행성 · 우선순위 · 기한(지난 기한 · 오늘 · 내일 · 이번 주 · 나중에 · 기한 없음)으로 바꿀 수 있고, 카드를 다른 열로 끌어 놓으면 그 속성이 바뀝니다(실행 취소 가능). 열 머리의 `+` 로 그 열에 바로 추가하고, 검색과 「완료 포함」으로 걸러 봅니다.
- **지금 집중 중 바**: 집중을 시작하면 입력창 바로 위에 붙습니다. 지금 하는 일과 행성 · 우선순위, 큰 타이머, 다음 단계(바로 체크), 멈춤, 완료 버튼이 있고, 여러 개를 태우면 나머지는 아래 칩으로 보여 누르면 바꿔 볼 수 있습니다.
- **할 일 보드 (데스크톱 왼쪽)**: 높음 · 보통 · 낮음 · 미정 순으로 묶인 할 일이 보입니다. 줄에 마우스를 올리면 3D 장면에서 그 위성에 흰 고리와 이름표가 뜨고, 줄을 누르면 카메라가 그 행성으로 다가가며 상세가 열립니다. 제목을 누르면 보드를 접을 수 있습니다.
- **우선순위 3단계**: 높음(주황빨강) · 보통(노랑) · 낮음(파랑) · 미정. 위성은 우선순위가 높을수록 크고 같은 색 고리가 붙으며, 기한이 지나면 고리가 깜박입니다.
- **정하는 방법**
  - 입력할 때 `!1` `!2` `!3`(또는 `!높음` `!보통` `!낮음`, `!`만 쓰면 높음). 입력창 오른쪽 우선순위 칩으로도 고를 수 있습니다.
  - 보드나 목록의 우선순위 아이콘을 누르면 메뉴가 뜨고 숫자 키 `1` `2` `3` `0` 으로 고릅니다.
  - 상세 화면 맨 위의 「우선순위」 줄에서 한 번에 선택합니다.
  - **우선순위 정리**: 미정인 할 일이 있으면 보드 아래 「정리하기」가 나타납니다. 한 장씩 보여 주는 할 일에 `1` `2` `3` 만 누르면 되고, `→` 로 건너뜁니다.

## 조작

| 동작 | 마우스 · 키보드 | 터치 |
| --- | --- | --- |
| 시점 돌리기 | 빈 공간 드래그, 방향키 | 한 손가락 드래그 |
| 확대 · 축소 | 휠, `+` `−`, 오른쪽 아래 버튼 | 두 손가락 오므리기·벌리기 |
| 행성 가까이 보기 | 행성이나 라벨 클릭 | 행성 탭 |
| 위성 끌기 | 위성을 누른 채 끌기. 노트북 패드는 탁 탁 두드려 끌기도 됩니다. 끄는 중 `Esc` 로 취소. 빈 공간을 끌면 시점이 돌아갑니다 | 위성을 손가락으로 바로 끌기. 끄는 위성은 손가락 조금 위에 떠서 보입니다 |
| 전체 보기로 돌아가기 | 빈 공간 두 번 클릭, `0`, 상단 「전체 보기」, `Esc` | 두 번 탭, 「전체 보기」 |
| 자동 회전 켜기·끄기 | `R`, 오른쪽 아래 버튼, 설정 | 오른쪽 위 버튼 |
| 조작 안내 다시 보기 | `?`, 오른쪽 아래 버튼 | 오른쪽 위 버튼 |

행성을 누르면 카메라가 그 행성 바깥쪽으로 다가가고, 위성 궤도가 화면을 향해 펼쳐지며 각 위성 옆에 할 일 이름표가 붙습니다. 이름표를 누르면 상세가 열리고, 이름표를 끌어 태양에 놓거나 이름표의 불꽃 버튼을 누르면 바로 집중이 시작됩니다. 가까이 본 상태에서 위성을 끌면 카메라가 잠시 물러나 태양이 보이도록 합니다.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 할 일 추가 | 아래 입력창에 쓰고 Enter. `#행성이름` `!1`~`!3`(우선순위) 「내일」「다음주 금요일」「오후 3시」「12/25」를 알아듣고, 입력하는 동안 행성·우선순위·날짜 칩에 미리 보여 줍니다 |
| 집중 시작 | 위성을 태양까지 끌어 놓기, 보드 · 목록 · 이름표의 불꽃 버튼, 상세 화면의 「태양에 올려 집중 시작」 |
| 완료 | 집중 바의 「완료」, 보드 · 목록의 동그라미. 실행 취소 가능 |
| 궤도로 되돌리기 | 집중 바의 멈춤 버튼, 또는 타오르는 위성을 행성으로 끌어 놓기. 타이머는 일시정지 |
| 카테고리 이동 | 위성을 다른 행성까지 끌어 놓기. 옮긴 뒤 알림에서 실행 취소할 수 있습니다. 목록 보기에서 카드를 다른 열로 끌어도 됩니다 |
| 보기 | 오늘(기본) · 전체 · 목록 · 캘린더. 캘린더는 오른쪽 위 「월 · 주」로 월간과 주간을 바꾸고 `←` `→` 로 넘깁니다. 캘린더에서는 할 일을 다른 날짜로 끌어 옮깁니다 |
| 오늘의 미션 | 태양이나 오른쪽 위 진행 링을 누르면 남은 일, 지난 일, 제안이 모입니다 |
| 행성 관리 | 설정에서 이름과 천체를 고르고, 삭제할 때 할 일을 다른 행성으로 옮길 수 있습니다 |

단축키: `N` 새 할 일 · `/` 또는 `Ctrl+K` 검색 · `1` `2` `3` `4` 보기 전환(오늘 · 전체 · 목록 · 캘린더) · `T` 오늘의 미션 · `+` `−` 확대·축소 · 방향키 시점 회전 · `0` 전체 보기 · `R` 자동 회전 · `?` 조작 안내 · `Esc` 닫기

Google Tasks 와 Microsoft To Do 에서 좋은 기능을 가져왔습니다: 나의 하루(오늘 할 일), 제안, 단계, 반복, 메모, 빠른 추가, 날짜와 시간, 캘린더 보기. 중요 표시는 3단계 우선순위로 확장했습니다.

## 캘린더 주간 보기와 연동

- **주간 보기**: 일주일을 7개 열로 펼쳐 날짜마다 할 일을 카드로 보여 줍니다. 시간이 있는 일이 먼저 시간순으로 나오고, 카드에서 바로 완료 체크, 다른 날짜로 끌어 옮기기(실행 취소 가능), 날짜 아래 「추가」로 그날 할 일 넣기가 됩니다. 휴대폰에서는 날짜별 세로 목록이 되고 오늘부터 보입니다.
- **내 캘린더로 보내기**: 캘린더 아래 「캘린더 연동」(또는 설정 → 데이터)에서 마감일이 있는 할 일을 .ics 파일로 받아 구글 · 애플 · 아웃룩 · 삼성 캘린더에 넣습니다. 시간이 없으면 하루 종일 일정, 있으면 30분 일정(10분 전 알림 선택)이 되고, 반복 설정도 함께 넘어갑니다.
- **할 일 하나만 보내기**: 상세 화면 마감 아래 「캘린더에 추가」에서 Google · Outlook(새 창으로 일정 만들기) 또는 .ics 파일을 고릅니다.
- **다른 캘린더 가져오기**: 다른 캘린더에서 내보낸 .ics 파일을 고르면 미리 보기 후 원하는 행성에 할 일로 넣습니다. 지난 일정은 뺄 수 있고, 반복 일정은 오늘 이후 가장 가까운 날짜와 반복 설정으로 바뀌며, 같은 파일을 다시 가져와도 중복되지 않습니다.
- 서버 없이 브라우저에 저장하는 앱이라 실시간 자동 동기화는 하지 않고, 파일로 주고받습니다.

## 기기별 사용

| 기기 | 방법 |
| --- | --- |
| Windows · Mac (Chrome · Edge) | 배포 주소를 열고 주소창 오른쪽 **설치** 아이콘 → 데스크톱 앱처럼 실행 |
| Mac (Safari 17+) | 파일 메뉴 → **Dock에 추가** |
| 갤럭시 · Android | Chrome 또는 삼성 인터넷 메뉴 → **홈 화면에 추가** / **앱 설치** |
| iPhone · iPad | Safari 공유 버튼 → **홈 화면에 추가** |

휴대폰에서는 상단 바가 두 줄로 바뀌고, 왼쪽 위 「오늘 할 일」 버튼으로 목록을 열며, 상세 화면은 아래에서 올라오는 시트(손잡이를 끌어내려 닫기)가 되며, 「지금 집중 중」 바는 입력창 바로 위에 붙고, 목록 보기는 열을 옆으로 넘겨 봅니다. 화면이 느려지면 렌더링 해상도를 자동으로 낮춰 부드럽게 유지합니다.

App Store · Play Store 에 올리려면 이 폴더를 네이티브 껍데기로 감싸면 됩니다.

```bash
npm init -y && npm i @capacitor/core @capacitor/cli
npx cap init "ORBIT" "com.example.orbit" --web-dir .
npx cap add ios      # Mac + Xcode 필요
npx cap add android  # Android Studio 필요
```

Android 는 [PWABuilder](https://www.pwabuilder.com) 에 배포 주소를 넣어 Play Store 용 패키지를 만들 수도 있습니다.
